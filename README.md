# Clementine Speech Therapy — Website

Marketing website for Clementine Speech Therapy, a speech-language pathology practice in St. Petersburg, FL.

**Live site:** [clementinespeech.com](https://www.clementinespeech.com)

---

## Pages

| Page | URL |
|---|---|
| Home | `/` |
| About | `/about` |
| Services | `/services` |
| FAQs | `/faqs` |
| Contact | `/contact` |
| Privacy Policy | `/privacy-policy` |
| Terms & Conditions | `/terms-and-conditions` |

## Tech Stack

- Plain HTML, CSS, JavaScript — no framework or build step
- Hosted on **GitHub Pages**
- Custom domain via **Namecheap**
